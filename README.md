## Описание проекта
Программа представляет собой графическое приложение на языке Python с использованием стандартной библиотеки `tkinter`. Приложение отображает квадратное окно размером 600×600 пикселей, полностью заполненное областью для рисования (`Canvas`), по центру которого расположена окружность радиусом 200 пикселей, вдоль которой движется точка с возможностью динамического изменения скорости и направления.

## Требования к системе
- **Python:** 3.9 или выше
- **ОС:** Windows / macOS / Linux
- **Библиотеки:** `tkinter` (встроенная)

## Установка и запуск
1. Клонируйте репозиторий: `git clone <ссылка>`
2. Создайте окружение: `python -m venv venv`
3. Активируйте: `venv\Scripts\activate`
4. Запустите: `python main.py`
